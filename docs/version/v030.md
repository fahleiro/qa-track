# QA Track v0.3.0

> Minor release — Device Farm: visualização web + suporte **iOS** rodando em **Linux** (open-source, sem Mac).

---

## Novidades

### 1. Device Farm com iOS (além de Android)

O node-agent agora descobre e exibe **devices iOS** junto dos Android, de forma unificada:

- **Descoberta/metadados iOS** via [libimobiledevice](https://libimobiledevice.org/) (`idevice_id` + `ideviceinfo`): modelo (ProductType → nome comercial), versão de iOS, fabricante.
- **Screenshot iOS** via [pymobiledevice3](https://github.com/doronz88/pymobiledevice3) (serviço DVT), pois `idevicescreenshot` não cobre iOS 17+.
- A listagem agregada e o detalhe do device passam a mostrar a plataforma correta (`iOS`/`Android`).

A arquitetura segue a mesma (hub-and-spoke): o dashboard agrega via fan-out e faz proxy autenticado do screenshot. O agent só ganhou uma camada `deviceService` que mescla Android (adb) + iOS (libimobiledevice/pymobiledevice3).

### 2. node-agent dockerizado para Linux (Android + iOS)

`node-agent/Dockerfile` (base `node:18-bookworm-slim`) inclui `android-tools-adb`, `libimobiledevice-utils` e `pymobiledevice3`. Scripts de apoio:

- `node-agent/run-docker.sh` — sobe o container `--privileged --network host` montando USB, socket do `usbmuxd`, pareamentos (`/var/lib/lockdown`) e a chave adb do host.
- `node-agent/setup-ios-tunnel.sh` — instala o serviço systemd `pmd3-tunneld` (tunnel RemoteXPC exigido pelo iOS 17+).

> **iOS é fundamentalmente host-level/Linux**: USB não passa para containers no Windows/Mac. Este suporte é pensado para um host **Linux** servindo como middleware de devices.

## Pré-requisitos iOS (host Linux)

1. `sudo apt-get install -y libimobiledevice-utils usbmuxd` e `sudo systemctl enable --now usbmuxd`.
2. Conectar o iPhone e **confiar** no computador (pareamento).
3. **Developer Mode** ligado no device (Ajustes → Privacidade e Segurança → Modo de Desenvolvedor). Se o item não aparecer: `pymobiledevice3 amfi reveal-developer-mode`, depois ligue e reinicie.
4. Tunnel RemoteXPC: `bash node-agent/setup-ios-tunnel.sh` (serviço `pmd3-tunneld`).
5. DDI: `pymobiledevice3 mounter auto-mount` (uma vez; personalizado para a versão de iOS).

Detalhes em [`docs/device-farm.md`](../device-farm.md) e [`node-agent/README.md`](../../node-agent/README.md).
