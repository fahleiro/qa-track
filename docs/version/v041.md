# QA Track v0.4.1

> Patch — Inspetor de elementos no gravador (estilo Appium Inspector), nativo.

---

## Novidades

### Inspetor de elementos (`/device-farm/:udid`)

Botão **Inspetor** no painel do gravador. Ao ligar, busca o `source` da tela e permite **selecionar elementos para debugar e montar locators** de automação — sem Appium.

- **Android**: overlay sobre o screenshot — **hover** destaca o elemento (caixa) e **clique** seleciona; o painel mostra `resource-id`, `text`, `content-desc`, `class`, `bounds`, `clickable`, `package` + **locator sugerido** (`id` > `accessibility id` > `text` > `xpath`). Coordenadas vêm do `uiautomator`.
- **iOS**: lista de elementos (via serviço de Acessibilidade) clicável → painel com `caption`, `spoken_description`, `identifier` + **locator sugerido** (`accessibility id`). O AX **não expõe coordenadas**, então não há caixas posicionais no iOS (isso exige WebDriverAgent assinado).

Também: arrastar na tela agora vira **swipe** (a imagem não arrasta mais).

---

## Compatibilidade

Sem quebras — mudança de frontend (`DeviceDetail.jsx`); o `source` já existia no backend (v0.4.0).

## Fora de escopo

Caixas posicionais e interação por coordenada no iOS dependem da trilha **WebDriverAgent assinado** (go-ios), cujo `/source` traz `rect` de cada elemento.
