# QA Track v0.4.0

> Minor release — **Gravador de interações** no Device Farm (POC nativo, sem Appium). Android completo; iOS no nível de Acessibilidade (AX).

---

## Novidades

### Gravador de interações (`/device-farm/:udid`)

Ao reservar um device, surge o painel **"Gravador de interações"**: você usa o aparelho pelo próprio QA Track e as ações são registradas (mapeamento de elementos + automação minimalista). Sem Appium — interação nativa via `adb` (Android) e `pymobiledevice3`/AX (iOS).

**Ações**
- **Tap por clique** na tela (escala a coordenada do screenshot → toque no device → captura o elemento sob o ponto).
- **Swipe** arrastando na tela (clique curto = tap; arrasto = swipe).
- **Gestos**: Home / Voltar / Apps (recents).
- **Set text** no campo focado.
- **Abrir app** (package Android / bundle id iOS).
- **Inspecionar tela**: lista os elementos visíveis (Android via `uiautomator`; iOS via serviço de Acessibilidade — *list-items*).
- **Log** das interações persistido na **sessionStorage** do navegador (chave `qatrack:rec:<udid>`), com **Exportar JSON** e **Limpar**. Descartado ao fechar a aba.

**Matriz por plataforma (POC, nativo)**

| Ação | Android | iOS nativo |
|---|---|---|
| tap + elemento | ✅ | ⛔ requer WDA assinado |
| swipe | ✅ | ⛔ requer WDA |
| home / voltar / apps | ✅ | ⛔ requer WDA |
| set text | ✅ | ⛔ requer WDA |
| abrir app | ✅ | ✅ |
| inspecionar elementos | ✅ | ✅ (Acessibilidade) |

### Arquitetura

- **node-agent**: novos endpoints `/agent/devices/:udid/{source,tap,gesture,text,swipe,launch,foreground}`. Android: `adb input tap/swipe/text/keyevent`, `uiautomator dump` (hit-test do elemento), `dumpsys window` (app em foco). iOS: `pymobiledevice3 developer accessibility list-items` e `dvt launch`.
- **Dashboard**: proxies em `/api/devicefarm/devices/:udid/*` (igual ao screenshot), com **JWT + lock obrigatório** do próprio usuário nas mutações; propaga `501` do iOS sem WDA.
- **Frontend**: painel no `DeviceDetail.jsx`; screenshot com `draggable=false` (arrastar = swipe, não move a imagem).

---

## Compatibilidade

Sem quebras. Banco inalterado. Os endpoints de interação são aditivos e exigem device reservado (lock).

## Status / fora de escopo

Esta é uma **POC experimental**. Próximos passos: tap-by-element no iOS (via `perform_press` do AX), registrar o app em foco em cada entrada do log, e a trilha WDA assinado (go-ios) para paridade total de UI no iOS — e, depois, eventual plugin Appium.
