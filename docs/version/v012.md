# QA Track v0.1.2

> Patch release — proteção de runs encerradas.

---

## Bugfix

### Runs encerradas eram editáveis
Quando um card era movido para **Finalizado** no Kanban (estado que automaticamente coloca a run vinculada em `Closed`), ainda era possível alterar o `result_status` dos cenários da run via API e via UI. Isso quebrava a semântica de "encerrado" e podia violar a regra de que cards só finalizam com todos os cenários em `Passed`.

#### Backend
- `PATCH /api/run/detail/:detailId/status` agora verifica o status da run associada antes do update.
- Run em `Closed` → retorna **HTTP 409** com mensagem: *"Run encerrada (card finalizado): resultado dos cenários não pode ser alterado."*

#### Frontend
- Na página de Runs, o `<select>` de resultado fica `disabled` quando `runDetail.status_title === 'Closed'`.
- Linha explicativa aparece no topo da tabela de cenários: *"Run encerrada — resultados não podem ser alterados."*
- Tooltip no select reforça a mensagem.
